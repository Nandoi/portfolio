
# Fernando Portfolio

A minimalist and responsive personal portfolio built with React, TypeScript, Tailwind CSS, and Vite.

This website showcases my technical skills, GitHub activity, and journey as an Information Technology student and aspiring software developer.

**[View Live Portfolio](https://fernandovidal.vercel.app/)**

---

## About the Project

Fernando Portfolio is a personal website created to document my growth in software development and web technologies.

It features a clean, monochrome design, responsive navigation, reusable React components, and a GitHub contribution calendar.

The portfolio will continue to evolve as I gain more experience and complete new projects.

## Getting Started

### Prerequisites

Install a compatible version of Node.js and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/Nandoi/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed by Vite.

### Other Commands

```bash
npm run lint
npm run build
npm run preview
```

## Deployment

The portfolio is deployed on Vercel and connected to the GitHub repository.

Changes merged into the `main` branch trigger a new production deployment.

**Live Website:** https://fernandovidal.vercel.app/
